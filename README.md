## 🧠 Overview

**OrbitalPSI-GPT** connects natural-language interaction with a structured 3D orbital implant design workflow.

The system is designed to allow clinicians to:

* inspect patient-specific orbital anatomy;
* review automated anatomical reconstruction;
* synthesize an initial implant geometry;
* iteratively modify design boundaries through text instructions; and
* retain supervisory control throughout the complete workflow.

The framework is intended to **reduce dependence on specialized CAD expertise and proprietary planning infrastructure**, particularly in resource-constrained research and surgical environments.

## ✅ Clinician-in-the-Loop Workflow

The complete workflow is organized around deterministic checkpoints **CP0–CP4**.

The clinician retains supervisory oversight and veto authority throughout the design process.

```text
┌─────────────────────┐
│  CP0 · Case Setup   │
└──────────┬──────────┘
           │
           ▼
┌─────────────────────────────┐
│ CP1–CP2 · Anatomy Review    │
└──────────┬──────────────────┘
           │
           ▼
┌─────────────────────────────┐
│ CP3 · Baseline Synthesis    │
└──────────┬──────────────────┘
           │
           ▼
┌─────────────────────────────┐
│ CP4 · Text-Driven Editing   │
└──────────┬──────────────────┘
           │
           ▼
┌─────────────────────────────┐
│ Clinician Review / Export   │
└─────────────────────────────┘
```

### `CP0` — Case Setup

The clinician provides a concise natural-language description of the case, including relevant information such as:

* defect laterality;
* fracture extent;
* anatomical considerations; and
* reconstructive requirements.

The system extracts the required information and initializes the reconstruction workspace.

---

### `CP1–CP2` — Anatomy Verification

Patient CT data and automatically generated anatomical models are presented for inspection.

> [!IMPORTANT]
> **Clinician approval is mandatory.**
> Implant synthesis does not proceed until the reconstructed anatomy has been explicitly reviewed and approved.

If the anatomy is considered inadequate, the workflow must be corrected or terminated before implant generation.

---

### `CP3` — Baseline Implant Synthesis

A baseline implant geometry is generated using the reconstructed anatomical reference and corresponding geometric design components.

The clinician reviews the initial geometry before proceeding to interactive refinement.

---

### `CP4` — Text-Driven Refinement

The clinician can iteratively modify implant geometry through conversational instructions.

Examples:

```text
Extend the posterior boundary by 1.5 mm.
```

The geometry is regenerated after each accepted instruction and returned for subsequent inspection.
